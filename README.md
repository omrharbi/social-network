# Social Network

## Description
This project is a social networking platform that allows users to connect, share content, and engage with others.

## Features
- User registration and authentication
- Profile management
- Feed for sharing posts and updates
- Messaging system
- Notifications for interactions

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/omrharbi/social-network.git
   cd social-network
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```

## Usage
- Register a new account to begin using the platform.
- Share content by creating posts, and engage with other users through comments and likes.
- Use the messaging system to communicate with friends.
